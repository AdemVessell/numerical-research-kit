# Provenance and scope

Developed by Adem Vessell with OpenAI Codex assistance, October 2026. AI agents
assisted implementation, documentation and review. These reviews are not
independent human validation. The comparison code was extracted and adapted
from the author's numerical research workflows.

MSE decomposition, the reverse-triangle bound, Euler and Heun time stepping,
and SHA-256 content hashes are established techniques. No mathematical novelty,
general research advantage, competitive estimator or learned model is claimed.
The synthetic example demonstrates software behavior on known equations.

The public package contains no model weights, proprietary data, research-session
transcripts, participant estimator source or private experiment records.
Only the Python standard library is required. The icon is an original geometric
SVG. Package assets and source use the accompanying MIT license.

The manifest uses the portable Agent Plugins format documented by OpenAI:
[packaging](https://developers.openai.com/plugins/build/plugins),
[skills](https://developers.openai.com/plugins/build/skills).
These interfaces can evolve. Compatibility checks and local tests do not imply
acceptance into OpenAI's public directory.
