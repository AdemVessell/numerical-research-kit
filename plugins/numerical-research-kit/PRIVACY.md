# Privacy — Numerical Research Kit 0.2.1

This package is maintained by Adem Vessell. Its Python scripts process the
numeric arrays, comparison metadata and file paths selected for the task.
The package has no network requests, telemetry, analytics, accounts or hosted
storage. The maintainer receives no data through the package's runtime.

Processing is for numerical comparison, bounds and verification. Outputs contain
supplied values/metadata and calculated results. They remain in files in the
execution environment until the user deletes them. The package does not
automatically delete files or impose a retention period. Users control which
files they provide, where outputs are written, and whether to retain or share
them. It creates new output files and refuses overwrites.

Codex, ChatGPT or another host may process prompts, selected files and tool
outputs under that host's own terms, settings and retention policies. Running
this package in a cloud execution environment is not a promise of on-device
processing. Absence of package telemetry does not change host behavior.

No personal data is required. Supply synthetic or non-personal numerical inputs.
Do not include credentials, identifiers, regulated records or private research
in public support reports. If you choose to file a public issue, its content is
visible to the maintainer and other repository visitors under the hosting
service's policies; removal and retention there depend on that service.
See [SUPPORT.md](SUPPORT.md) for reporting guidance.
